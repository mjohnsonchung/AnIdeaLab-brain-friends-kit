# The brain and your PC

The brain's own skills for running this brain: its first session, how to work with an owner new to agents, where things go, the weekly tidy-up, the PC runner, the upload point and keys. All are the brain's own: written for this brain, and changed freely. A new skill on this topic gets a line here saying when to use it; a copied one goes under a "Copied" heading below them.

## The brain's own
- [getting-started](../getting-started/SKILL.md): the first session in a new brain: who the owner is, their first notes, testing the PC runner, and a tour.
- [guide-mode](../guide-mode/SKILL.md): how to work with an owner new to AI agents: say the ask back, size it, agree a plan, check in.
- [brain-spec](../brain-spec/SKILL.md): where each kind of thing goes in the brain and what shape it takes, and how to apply a brain update from AnIdeaLab.
- [brain-audit](../brain-audit/SKILL.md): the weekly tidy-up, when the owner says yes to it.
- [my-pc](../my-pc/SKILL.md): run commands and jobs on the owner's PC through the `my-pc` runner, and check or fix its setup.
- [windows-powershell](../windows-powershell/SKILL.md): the traps in Windows PowerShell 5.1 that break scripts and commands for the owner's PC (double quotes stripped on the way to programs, `$name:` in strings, stderr as errors, encodings), and how to check a script first. Read before writing any PowerShell.
- [add-a-key](../add-a-key/SKILL.md): get a key only the owner can make (a service's API key, a GitHub token) into this brain's GitHub secrets, or a site host's, with one command they paste: the page opened for them, the key read in hidden and checked.
- [upload-point](../upload-point/SKILL.md): the owner's Upload point window, and My brain in Send to, for giving the brain files and folders: what's waiting, and how to sort it into the brain, moving files and learning code repos where they are.
