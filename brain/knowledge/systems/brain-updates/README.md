# Brain updates

Matt, who made the starter kit this brain was started from, sends updates to brains like it from AnIdeaLab: fixes, new rules and new parts, through a public repo. An update counts as a message from the owner. The weekly tidy-up checks for new ones and applies them ([how](../../../skills/brain-spec/SKILL.md#brain-updates)).

**On kit update:** none applied yet; this brain started from the kit made on {KIT_DATE}.
