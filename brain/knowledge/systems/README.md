# Systems

What each system is and how it's set up. How to use one, when that's the same from job to job, is a skill.

<!-- index:start -->
- [brain-updates/](brain-updates/README.md): Brain updates from AnIdeaLab: which one this brain has, which the owner skipped, where they come from, and a report of each one applied. Read before checking for or applying a brain update. [the-brain]

- [brain-graph](brain-graph.md): The brain graph, the Obsidian view that replays the brain's growth from git history: opening it, reading it, its settings, and the rules for changing it. Read before touching its plugin or explaining it. [the-brain]
- [keys-and-accounts](keys-and-accounts.md): The outside accounts and keys the brain uses, by name only, and how the owner adds a key. Read before using, connecting or closing an account, or when a job needs a key. [the-brain]
- [my-pc](my-pc.md): The owner's Windows PC: how agents reach it (the my-pc runner), the folder layout in C:/AI-Brain-Link, and what's on it. Read for facts about the PC; how to run a job is the my-pc skill. [the-brain]
- [obsidian-setup](obsidian-setup.md): How the owner sees and edits the brain in Obsidian on their PC: the setup, syncing with GitHub, what the map's colours and lines mean, and the shared settings agents may change. Read before touching .obsidian/ or explaining the map. [the-brain]
- [routines](routines.md): Every routine in the brain (reminders, timers, scheduled jobs) and the rules for them. Read before adding, changing or checking a routine. [the-brain]
- [sign-off-links](sign-off-links.md): Which AnIdeaLab.com page the sign-off links to, by the reader's field. AnIdeaLab's file, refreshed from the kit repo by itself: never edit it here. Read before signing off an email to someone outside. [the-brain]
- [upload-point](upload-point.md): What's waiting at the upload point: files and folders the owner dropped on the Upload point window or sent with Send to, My brain, listed by path, for an agent to sort into the brain. Read when the owner mentions dropping something. [the-brain]
